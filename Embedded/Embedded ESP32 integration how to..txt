----------- HAPTIC MOTORS -------------

There are 3 haptic motors. 

See my example code which works for 1 haptic motor. (IN MY GITHUB REPO dir: "Embedded/Working LRA")

my code should be re-configured for 3 haptic motors. 

the esp32 talks to haptic motor drivers with I2C communication protocol.

the i2c protocol has 2 main wires SDA and SCL, SDA is for Data transmission and SCL is for clock. 

on the ESP 32 the SDA = GPIO21, SCL = GPIO22 (PINS)

there is also a an interrupt pin which is used for reading faults and should be added for debugging
the interrupt pin is called NIRQ = GPIO 27 (PIN)

please see my code as the haptic drivers need specific settings to work properly with the haptic motors!

NOTE : all three motors are LRA, the motor drivers are DA7280, DA7281, DA7282

the difference in motor driver names is simply the I2C address burned into them.

-------------Bluetooth Link button -------------

like any other Bluetooth device, there is a link button. 

it should work in some way that if you hold the button for a certain amount of time
then the device will go into Bluetooth pairing mode and begin searching for a Bluetooth connection

the BT link button is on pin GPIO5. 

this is a standard momentary push button so when it is pushed the pin goes to ground.

----------- speakers with DAC ---------------
still need to get working but hopefully works on PCB
if we use the built in PCM5102A 32 bit dac then it must be configured using the I2S protocol. 

the esp32 will transmit the received Bluetooth audio through I2S protocol and will be converted to analog externally. 

using a library you should be able to set some settings for the DAC. 

off the top of my head im thinking:

stereo 16 bit rate, 44.1kHz sampling frequency. (set in code)

The I2S transmission pins on the esp 32 are:

LRCK : GPIO16
DIN : GPIO17
BCK : GPIO18

no MCLK! (master clock)

GPIO 1 is the transmission pin
